# Rust Auto Updator v0.4.1

Extends exact asset discovery to unversioned names such as `Product-windows-x64.exe`, `Product-x86.exe`, and `Product-windows.exe`.

Architecture aliases remain separate: amd64/x64/x86_64, i386/x86/i686, and arm64/aarch64. Matching architecture-qualified names take precedence over names with no architecture, even when several CPU builds are published together. Package architecture and PE machine verification remain mandatory after download.

Tests exercise each alias with and without a version/platform on Windows and Ubuntu, mixed-architecture releases, generic fallbacks, duplicate names, invalid digests and compatibility with historical names.
