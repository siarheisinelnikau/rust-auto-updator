Rust project audit — 2026-11-01 (Europe/Minsk)

Scope: 23 Windows applications and the rust-auto-updator workspace, 24 repositories.
Work was delegated to repository-specific subtasks. No computer-use APIs, OS
input injection, remote Git operations or publishing were used.

Shared implementation: rust-auto-updator commit e1c6ceb.
All 23 application manifests now reference the sibling shared core. Product
adapters retain their own repository/version/assets, UI, settings and restart
arguments; common discovery/download/verification/replacement lives in the core.
Stable startup checks, persisted opt-out, manual checks and user-initiated
installation are preserved. Existing updater protocols were adapted where needed.
Core tests/native fixtures cover verified replacement and failed-startup rollback.
Independent source review found regressions in startup health and durable errors;
those findings were fixed and rechecked before final commits.

Windows interfaces use native CPU/GDI or egui CPU rasterization with GDI.
SecondScreen's UI OpenGL renderer was replaced. Its experimental IddCx virtual
display driver still uses required D3D11 surfaces and was not run.
Existing non-Windows graphics fallbacks were not rewritten or runtime-certified.

Final executable icon resources were loaded/drawn without executing the target
entrypoint and the resulting PNGs inspected. Missing EXE resources/native sizes
and window/taskbar bindings were repaired. Tray art uses native small-icon
metrics where present. A resource proof does not certify Explorer caching, actual
OS tray appearance/clicks, menus, Alt-Tab, mixed-monitor DPI or perceived lag.

Formatting, strict Clippy and optimized builds passed. Focused changed-code
tests passed. The SpaceSniffer complete library suite has two sandbox-denied
hardlink/junction fixture tests (82/84 passed); this is an explicit remaining gap.
Hardware/network/OS-input tests intentionally skipped are reported per project.
Zero sampled CPU is timer-quantized, not a claim of zero CPU cycles. GPU/desktop
compositor latency and subjective responsiveness were not measured.

Building an app or running standalone CI requires provision of the sibling
rust-auto-updator source; the workspace has not been published as a dependency.
Declared shared MSRV is 1.95; Rust 1.96.1 was exercised. Real updates were not
installed into the user's applications. Update replacement tests used isolated
fixtures only.

DownloadManager was also being edited in another chat. Our migration/evidence
commits preserve that chat's UI/documentation/screenshot work.

Thirteen applications have bounded optimized native rendering measurements.
Ten have no fresh native idle/hidden measurements because local AGENTS prohibit
GUI launch; source/tests/resource proofs and available offscreen captures are
reported separately. No universal full-workload performance pass is claimed.
