# Rust Auto Updator v0.3.1

This patch completes the Ubuntu/Debian restart handling introduced in v0.3.0.
The restart helper now recognizes an exited parent even when its launcher has
not yet reaped the process. Such a zombie no longer causes an unnecessary wait
before opening the updated application. A real child-process regression test
covers that case and confirms that a running parent is still distinguished.

Debian updates retain package identity, architecture, size and SHA-256 checks,
polkit authorization, apt ownership, and a responsive host while installation is
pending. Windows replacement and rollback behavior is unchanged. Windows and
Linux CI checks must pass before the source distribution is published.

The source archive contains core and optional egui crates at version 0.3.1.
The v0.3.0 release and its assets are retained unchanged.
