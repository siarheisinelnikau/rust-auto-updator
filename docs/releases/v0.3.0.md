# Rust Auto Updator v0.3.0

Applications can now install verified Ubuntu/Debian updates through the system
package manager, using the same release discovery and download pipeline as
Windows portable applications. The core and optional egui crate versions are
both 0.3.0 in this source distribution.

- `Config::debian` selects the package and architecture-specific `.deb` asset.
- Repository, version, size and SHA-256 checks are shared across installers.
  Debian control metadata must also match the expected package, version and CPU
  architecture before apt is invoked.
- Only executables belonging to the configured installed package can update it.
  Source builds must first install a `.deb`.
- Run `handoff` on a worker. Ubuntu requests administrator authentication through
  polkit; apt manages dependencies and package ownership, without package removals.
  Cancelled or failed installation keeps the original application open.
- Successful installation starts an unprivileged restart helper, which waits for
  the host to save/exit before launching the installed application with its session
  arguments. Private staging is cleaned after restart.
- Windows retains its existing executable replacement, backup and rollback path;
  `Config::new` still selects that mode. The Debian backend uses package-manager
  recovery and does not claim automatic EXE-style rollback.

Ubuntu checks cover real `.deb` metadata, wrong identity/version/architecture,
size/hash rejection, cancellation before network activity, package command
arguments, staging permissions and cleanup boundaries. The CI workflow runs
both the Windows native smoke checks and the Linux tests before publishing.
The optional egui panel remains presentation-only; hosts own asynchronous
installation, persistence and shutdown.

This release distributes source and checksums. It does not install software on
its own or publish to crates.io. See the README for integration instructions.
