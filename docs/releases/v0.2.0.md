# Rust Auto Updator v0.2.0

This source release adds translated update panels and an optional light theme while preserving existing integrations.

## Added

- Complete English, Russian, French, German, Spanish and Italian text for update actions, startup preferences, progress and status headings.
- `show_localized` with stable language codes, regional-code handling and English fallback, plus `show_with_text` for application-owned catalogs.
- Optional light/dark `Theme` and semantic `Palette` APIs with localized selector labels. The compiling host example demonstrates immediate Language and Theme changes and the values applications should persist.

## Improved

- Shared cards follow the host's current visuals, so a light host no longer receives a fixed dark card.
- Secondary text contrast is checked across both shared palettes, including control, hover and active surfaces.
- Source packaging reads an explicit source-release version and includes the matching release notes.

## Compatibility and validation

Both Cargo packages remain at `0.1.0`; this is a `v0.2.0` source release, not a new crates.io package. Existing English `show`, dark-theme functions, palette exports and consumer pins remain supported. Consumers explicitly adopt the new source revision before using the new APIs. The library still owns no renderer, window, tray or settings file. The host persists preferences and supplies the settings controls.

Catalog, language-code, placeholder, theme-switch and palette-contrast regressions run alongside the existing updater tests. Rendered language/light-theme screenshots and consuming-application idle/hidden behavior are outside this library's headless verification. Technical error details and upstream release notes are retained verbatim beneath translated headings.

The distribution is `RustAutoUpdator-v0.2.0-source.zip` with `SHA256SUMS.txt` and the MIT notice. There is no application EXE or installer. Portable update installation continues to target writable Windows executables; these additions do not expand platform support.
