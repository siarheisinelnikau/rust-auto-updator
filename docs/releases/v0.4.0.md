# Rust Auto Updator v0.4.0

Adds optional platform-qualified asset names for Windows executables and Debian packages. Hosts set `asset_platform` to `windows` or `ubuntu`; discovery checks the full product/version/platform/architecture filename before progressively simpler names and explicit historical aliases.

Matching remains exact and repository-bound. A corrupt or ambiguous preferred asset fails verification instead of silently selecting a weaker fallback. Debian aliases cannot select an EXE. Existing configurations retain their previous names unless the host opts in.

Publish compatibility copies under the previous filenames to keep installed older clients updating. Tests cover candidate order, shuffled assets, each fallback, foreign architectures, malformed digests, duplicate preferred names, and unsafe aliases.
